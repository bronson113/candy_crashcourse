Rules

  • Swap 2 adjacent candies to match 3 or more in a row or column.

  • Drop the Nut (N) into the gold Exit target cell before running out of swaps — the Exit can sit anywhere in its column (in Levels 2 & 3, drop the Nut just 1 cell into the Exit directly below it).
  • Dark Chocolate blocks gravity and cannot be swapped.

How to Decode the Flag

Of the 129 initial legal swap locations on Level 3, ignore the leftmost horizontal swap at (1, 2)–(2, 2). Read the remaining 128 vertical swap locations left to right as bits 0..127 (1 if swapped, 0 if untouched) to form key = Σ(biti << i), then decode the 128-bit integer as 16 big-endian ASCII bytes (bit 127 = MSB of byte 0, bit 0 = LSB of byte 15). (There's no flag format — the 16-byte ASCII key itself is the answer.)
